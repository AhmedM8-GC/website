Automation — Telegram AI Agent (n8n)

This project connects a Telegram bot to an AI agent using n8n workflows. The n8n logo above is included in the project folder.

View repo Open bot on Telegram

What it does

  • Handles user conversations on Telegram and sends them to an AI model for context-aware replies.
  • Triggers n8n flows via webhooks to perform actions such as fetching patient records, scheduling appointments, or generating summaries.
  • Persists minimal conversation state and supports external API integrations.

Tech stack

Telegram Bot API · n8n · AI model (hosted or external LLM) · simple storage (DB or cloud store) · webhooks & workflow automation

View repo Open bot on Telegram Back to projects

Architecture (high level)

  1. User → Telegram bot → Telegram API
  2. Telegram webhook → n8n workflow
  3. n8n calls AI model (LLM) and other APIs, stores results, and sends messages back via Telegram
